# BAGEL

## 基本信息

- 模型名称：BAGEL。
- 精确版本：BAGEL-7B-MoT；当前本地 NF4 量化包版本待确认。
- 发布机构：ByteDance-Seed。
- 官方仓库：https://github.com/ByteDance-Seed/Bagel
- 官方模型页：https://huggingface.co/ByteDance-Seed/BAGEL-7B-MoT
- 官方论文或技术报告：https://arxiv.org/abs/2505.14683
- 模型定位：统一多模态理解与生成模型，支持图像编辑。
- 是否支持文本指令图像编辑：是。
- 是否支持多图输入：待确认。
- 权重是否开放：是。
- 代码是否开放：是。
- 许可证：Apache-2.0。
- 商业使用状态：需按 Apache-2.0 及组织合规要求复核。
- 模型规模：官方仓库说明为 7B active / 14B total。
- 推荐推理精度：官方提供普通与量化运行路径；精确推荐待具体版本确认。
- 是否存在量化版本：存在 NF4、INT8 等社区/官方运行支持信息；当前本地使用 NF4。
- 官方硬件建议：官方 README 提到 32GB+ VRAM 或多 GPU，12-32GB VRAM 可使用 NF4。
- 当前是否具备本地测试条件：具备。
- 当前测试方式：本地 NF4。
- 测试状态：已本地测试。

## 当前已知实验记录

- GPU：NVIDIA RTX 4070 Ti Super 16GB。
- 单次图像编辑时间：约 75 秒。
- 当前能够正常得到图像编辑结果。
- 当前仓库未提供 BAGEL 输出图片文件。

## 待确认

- 是否为预热后时间。
- 是否包含模型加载。
- 推理步数。
- Guidance 参数。
- 输入输出分辨率。
- CPU offload。
- 峰值显存。
- 峰值系统内存。
- 重复运行平均时间。
- 更强 GPU 上的运行表现。

## 当前结论边界

BAGEL NF4 已能在本地完成特定图像编辑任务，但当前约 75 秒/次的延迟偏高。当前不能据此判断服务器部署后的速度，也不能把输出路线视为真实可执行无人机航线。
