## 本用例固定差异

- 建筑类型：异形建筑。
- 任务类型：优化扫描航线生成。
- 结构重点：弧形面、倾斜面、突出结构、凹陷区域、顶部区域。
- 扫描层次：较少主扫描路线覆盖主要表面。
- 默认要求：10 m 有效探测范围示意，区分主扫描路线、辅助路线、顶部补扫路线和覆盖范围，并保留图例。
