## 本用例固定差异

- 建筑类型：规则建筑。
- 任务类型：基础扫描航线生成。
- 结构重点：清晰正立面、可见侧立面、转角。
- 扫描层次：多层水平扫描路线。
- 默认不要求：10 m 探测范围、顶部补扫、图例、覆盖范围。

## 仅对 TC-01 生效的补充说明

`扫描目标是画面中的白色主体建筑，重点观察正立面、侧立面和转角上的路线连续性。`

## 预期观察重点

`是否正确锁定规则建筑主体；是否能画出围绕主体的连续主路线；是否出现穿墙、漂浮或无关曲线。`
