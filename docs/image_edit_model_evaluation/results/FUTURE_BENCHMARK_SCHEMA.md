# 未来 Benchmark 字段

当前不强制填写以下字段。后续有服务器资源和统一协议后，可扩展到完整实验表。

## 运行环境

- Git commit。
- 操作系统。
- Python / CUDA / PyTorch / Diffusers / Transformers 版本。
- GPU 型号、数量和显存。
- CPU 型号。
- 系统内存。
- 驱动版本。

## 推理参数

- Seed。
- 推理步数。
- Guidance / CFG。
- 输入分辨率。
- 输出分辨率。
- 冷启动时间。
- 预热后时间。
- P50。
- P95。
- 峰值显存。
- 峰值系统内存。
- CPU offload。
- 量化方式。

- 失败类型。
- 人工评分。
- 人工盲评一致性。
- 自动原图保持指标。
- 结构正确性指标。
- 路线元素完整性指标。
- 重复运行稳定性。
