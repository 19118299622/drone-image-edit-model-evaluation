# 评分体系占位

当前尚无统一评分标准。当前版本不计算综合分，不输出模型总排名，优先进行原始图、Prompt、参考效果和模型输出的可视化对比。

## 未来可扩展维度

- 目标识别正确性。
- 航线是否覆盖主要可见表面。
- 航线是否跟随建筑结构。
- 主路线、辅助路线、补扫路线、起点、终点和方向箭头是否完整。
- 原图保持程度。
- 无关重绘程度。
- 结构错误类型。
- 结果稳定性。
- 延迟、显存和内存占用。
- 人工盲评一致性。

## 当前不做的事情

- 不计算综合分。
- 不输出模型排名。
- 不把参考效果作为唯一正确答案。
- 不验证 10 m 探测范围的真实物理准确性。
- 不判断输出是否可直接飞行。
